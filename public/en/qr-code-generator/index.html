Frequently asked questions

Will my QR code ever stop working?

No. A static QR code contains the data itself and does not depend on our website.

What is the difference between static and dynamic QR codes?

Dynamic codes point to a redirect link owned by a company, so they can be changed or switched off. Static codes encode your content directly.

Can I use the QR codes commercially?

Yes, free for any use, including print and packaging.

Does the Wi-Fi QR code share my password with you?

No. The code is generated in your browser.

Does adding a logo break the code?

We automatically use the highest error correction when a logo is added. Always test-scan.
