How to use it

  1. Choose a PDF file.
  2. Type page ranges such as 1-3, 5, 8-10, or tick "Every page as a separate file".
  3. Click Split and download each new PDF.

Features

  • Any number of page ranges
  • One-click "every page" splitting
  • Original quality and text kept
  • Arabic comma (،) accepted in ranges

Honest limitations

Each range downloads as its own file (no ZIP yet). Password-protected PDFs must be unlocked first.

Frequently asked questions

How do I extract a single page?

Can I split every page into its own file?

Yes, tick "Every page as a separate file".

Is the text still selectable after splitting?

Yes. Pages are copied without changes.

Are my files uploaded?

No, splitting happens in your browser.
