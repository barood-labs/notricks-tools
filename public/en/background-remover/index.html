How to use it

  1. Open the tool and choose a photo (the AI model downloads once, then is cached).
  2. Pick a background: transparent, a color, your own image or a blur of the original. Or choose a preset.
  3. Fix any leftovers with the erase/restore brush, then download PNG or JPG.

Features

  • Full original resolution, no watermark, no daily limit
  • Presets: marketplace product (white, square), ID/passport photo sizes, sticker with white outline
  • Erase/restore touch-up brush with undo
  • Fast model for phones; best-quality model on computers with WebGPU
  • Batch many photos to one ZIP with the optional $4 one-time Pro

Honest limitations

The first run downloads the AI model (about 114–224 MB for the fast model, about 489 MB for the best one). On phones without WebGPU, a large photo can take 10–60 seconds. Very fine hair, fur against similar colors, glass and smoke are not always perfect; use the brush. ID photo presets only resize and recolor; check your country's official rules (expression, lighting, head size) before submitting.

Frequently asked questions

Is it really free at full resolution?

Yes. There is no credit system and no watermark. Pro ($4 once) only adds batch-to-ZIP and hides ads.

Are my photos uploaded?

No. The model runs in your browser. Only the model files are downloaded, from the Hugging Face CDN, once.

Which AI model is used?

BiRefNet (MIT licence), run with transformers.js and ONNX Runtime Web, via WebGPU when available or WebAssembly otherwise.

Why is it slow on my phone?

Phones without WebGPU run the model on the CPU. Choose the Fast model and smaller photos for quicker results.

Can I use the result commercially?

Yes, the output is yours. Make sure you own the rights to the original photo.
